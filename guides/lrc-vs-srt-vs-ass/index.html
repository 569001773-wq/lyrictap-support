LRC vs SRT vs ASS: which format is right?

Compare LRC line timestamps, SRT subtitle intervals and ASS styling or karaoke timing, with syntax examples and practical recommendations.

LRC: a timestamp at the start of each line

[00:12.40]First lyric line
[00:16.80]Second lyric line

Basic LRC is compact and readable. Some enhanced variants offer finer-grained timing, but a simple line-start LRC does not automatically produce per-syllable karaoke.

SRT: start and end intervals

1
00:00:12,400 --> 00:00:16,700
First lyric line

SRT is designed for time intervals rather than lyric-line starts. It is commonly imported into subtitle and video workflows.

ASS: advanced styling and karaoke

Advanced SubStation Alpha (.ass) can define styles, on-screen position and karaoke effects. Tags such as \k express durations in centiseconds. Actual behavior depends on the subtitle renderer and its supported features.

Which file should I choose?

  • Use LRC when your music player supports scrolling lyrics.
  • Use SRT for video editor subtitle timelines.
  • Consider ASS for styled karaoke where the renderer supports it.
