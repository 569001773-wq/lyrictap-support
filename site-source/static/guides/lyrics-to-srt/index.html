How to turn lyrics into SRT subtitles

Learn the SRT subtitle format, correct time intervals, how to sync lyrics and export a compatible subtitle file for video editors.

Open free browser studio →

What an SRT subtitle file contains

SRT subtitles are numbered blocks. Each block has a start and end time in the HH:MM:SS,mmm format, followed by one or more lines of text.

1
00:00:12,400 --> 00:00:16,750
Midnight moving through the glass

2
00:00:16,800 --> 00:00:21,100
Every streetlight turns to gold

This example uses illustrative timestamps, not measurements from a real recording.

Convert lyrics into timed subtitles

  1. Choose your audio file in the free browser editor.
  2. Paste lines in their performed order, including repeating choruses.
  3. Play the track and tap as each line begins.
  4. Adjust timing while listening again; export with the SRT button.
  5. Import your file into the destination video editor and check the caption intervals.

How to avoid overlapping or reversed captions

A valid subtitle interval must end after it begins. The LyricTap web editor checks that line-start timestamps increase and calculates an end time before the next line starts. Closely spaced lyrics and silence between verses should be reviewed in your editing software; a fixed end time cannot fit every song.

Should I export LRC or SRT?

For synchronized scrolling lyrics in a compatible player, use LRC. For video editors that expect caption start and end times, SRT is usually appropriate. If you need advanced karaoke rendering and styling, see the LRC, SRT and ASS comparison.
