歌詞同期のやり方：LRCを作成する

ボカロ・歌ってみた向けの歌詞同期ガイド。音源からLRCを作る手順、SRTとの違い、サビの繰り返しやタイミングの修正方法。

無料ツールを開く →

4ステップで歌詞を同期する

  1. 利用できる音声ファイルを用意してブラウザで開きます。
  2. 歌詞を音源どおりの順番で貼り付けます。繰り返すサビも省略しません。
  3. 再生し、各行の開始位置でタップしてタイムスタンプを付けます。
  4. 0.1秒ずつ調整し、LRCまたはSRTをダウンロードします。

無料のLRC編集画面へ →

LRCファイルの例

[00:12.40]最初の歌詞
[00:16.80]次の歌詞

LRCは各行の先頭に分・秒・百分の一秒を記録します。数値は説明用です。歌詞を表示したいプレーヤーの対応形式も確認しましょう。

LRCとSRTの使い分け

LRCは曲に合わせて歌詞をスクロール表示する用途に向いています。SRTは開始・終了時刻を持ち、動画編集ソフトの字幕に向いています。カラオケ効果にはASS形式のような高度な形式もありますが、無料ウェブツールの出力はLRC・SRT・TXTです。

ボカロ・歌ってみたでの確認ポイント

  • サビを繰り返す位置を間違えない。
  • 間奏のあとの歌い出しを再確認する。
  • 早口の部分は何度か再生し、0.1秒単位で修正する。
  • 公開する音源、歌詞、画像の利用権限を確認する。
