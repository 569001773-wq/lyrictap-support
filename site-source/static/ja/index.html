iPhone・iPad版の新機能

曲全体のAI同期が完了した後、翻訳、歌詞の編集、動画制作へ進めます。以下はiOSアプリの機能であり、ブラウザの手動LRCツールとは別です。

多言語AI歌詞翻訳翻訳先言語を選び、訳詞を行ごとに編集。原文と訳文を同時表示し、LRC・SRT・TXTの二言語書き出しにも対応。
5つの動画比率・文字色9:16、16:9、1:1、4:5、3:4。歌詞動画の文字色、縁取り色、太さを調整し、二言語表示にも対応。
ボーカルと伴奏を分離全曲AI同期でボーカルと伴奏を分離。期限内にそれぞれダウンロードして保存できます。
編集・書き出し歌詞の行タイミング調整やMP4書き出しに対応。手動カラオケ打点は原文ASS・Enhanced LRCファイル用です。

AI翻訳と歌詞動画には全曲AI同期の完了が必要です。言語や機能はアプリのバージョンによって異なります。

歌詞動画を作る前に

iOSアプリで歌詞動画を作成するには、全曲AI自動同期の完了と背景画像が必要です。9:16、16:9、1:1、4:5、3:4の比率、文字色・縁取りを設定できます。原文と翻訳の二言語動画にも対応。カラオケの単語タイミングは手動で作成し、原文ASS・Enhanced LRCへ書き出します。

無料のLRC作成方法

  1. ブラウザで音声ファイルを選びます。
  2. 歌詞を1行ずつ入力します。
  3. 再生しながら歌い出しでタップします。PCではSpaceキーでも操作できます。
  4. タイミングを調整し、LRCまたはSRTを保存します。

手動同期とAI自動同期

ウェブの無料ツールでは、音声をアップロードせずに手動でタイムスタンプを作れます。iPhone・iPad版のLyricTapなら、有料クレジットを使って歌声に合わせたタイムスタンプを作成できます。全曲を同期したら、翻訳先言語を選んで二言語歌詞を編集し、好きな背景画像と文字色で歌詞動画を作成できます。分離したボーカル・伴奏音源も保存できます。

ボカロP・歌ってみた制作者にも

同じサビを繰り返す曲や間奏が長い曲では、歌詞の表示がずれないよう各行の開始時刻を確認しましょう。日本語の歌詞同期ガイドでは具体的な作り方を解説します。

保存とプライバシー

ブラウザには歌詞とタイミングを保存できますが、音声そのものは保存しません。ページを再読み込みしたら音声を再選択してください。無料ウェブツールではAI音声認識もMP4出力も行いません。
